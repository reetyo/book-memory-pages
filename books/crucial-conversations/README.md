## 记忆结构

不按 13 章排列，而是按“基础概念＋准备／展开／结束对话”整理成四张主题卡片：

1. **何为关键对话**：高风险、不同意见、强烈情绪；共享观点库；沉默与暴力。
2. **怎么准备**：选对话题（CPR）、从心开始、区分事实与解释、识别三种自我开脱的故事。
3. **怎么进行**：观察气氛与保证安全、共同目的（CRIB）、表达自己（STATE）、倾听与回应（AMPP＋ABC）、接收反馈（CURE）。
4. **怎么结束**：明确决策方式、约定谁做什么和何时完成、记录与跟进（WWWF）。

每个缩写都有完整中文动作、对应英文与自编话术。首页显示四张卡片，点开查看详细内容；也支持全部展开与打印。
