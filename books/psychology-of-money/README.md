# 《金钱心理学（全新增订版）》· 按章序排列的四张记忆卡

- 作者：Morgan Housel（摩根·豪泽尔）。原书名：*The Psychology of Money*。
- 版本基准：用户确认采用中信出版 2026 年全新增订版，正文22章，ISBN 9787521785036；不再使用原版20章的编号。
- 排列规则：卡片内严格按章号递增。四个连续章节组覆盖第1–22章，不重复、不跳章。序言与附录不另设卡片。
- 分组名称、每章短标题与要点为本页助记改写，不冒充原书的分部或章节标题。每章是简短读后回忆线索，不是完整章节摘要。
- 新版第19、20章独立列出；原版末尾的总结与个人方案，在本页分别对应增订版第21、22章。
- 目录及版次已核对出版方官方店铺和得到正版电子书页面；第19章主要依据出版方公开试读，第20章依据出版方介绍的章节主旨。其余主题结合作者公开文章和书中节选核对，未声称逐页读取用户手中版本。
- 自编例子、串联语、口诀和复习问答均为本页创作；不含书籍全文、大段引文或个人账户信息。

## 阅读方式

打开 `index.html` 查看四卡总览，每卡直接标明章节范围。点击卡片底部的章节标题，使用浏览器原生 details/summary 在卡内展开，单张卡及回忆题均不依赖 JavaScript；支持键盘操作。脚本可用时提供一键展开和打印，脚本不可用时自动隐藏这些按钮。展开后按原书顺序逐章回忆。纯静态，无需登录或安装。返回书架链接为 `../../index.html`。
